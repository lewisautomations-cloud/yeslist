# YesList at Xavier

Xavier students find alumni who already said yes to helping them, with advice, a paid project or an internship. Class demo for MGMT 342, fall 2026, by Yohan Lewis.

- `index.html`: the page that explains YesList
- `app/index.html`: the app (one file, no build step; sample alumni are invented)

To publish: Settings → Pages → Deploy from a branch → `main`, folder `/ (root)`.
